参数更新

随机梯度下降法
使用参数的梯度，沿梯度方向更新参数，并重复这个步骤多次，从而逐渐靠近最优参数，这个过程称为随机梯度下降法（stochastic gradient descent），简称 SGD

class SGD:
    def __init__(self, lr=0.01):
        self.lr = lr

    def update(self, params, grads):
        for key in params.keys():
            params[key] -= self.lr * grads[key]

Momentum
公式（α=动量系数，常用0.9）
v=α∗vlast−lr∗∂L∂WW=W+vv = α * v_{last} - lr * \frac{\partial L}{\partial W}\\ W = W + vv=α∗vlast​−lr∗∂W∂L​W=W+v

class Momentum:
    def __init__(self, lr=0.01, momentum=0.9):
        self.lr = lr
        self.momentum = momentum
        self.v = None

    def update(self, params, grads):
        if self.v is None:
            self.v = {}
            for key, val in params.items():
                self.v[key] = np.zeros_like(val)
        for key in params.keys():
            self.v[key] = self.momentum * self.v[key] - self.lr * grads[key]
            params[key] += self.v[key]

AdaGrad
随着学习的进行，使学习率逐渐减小。
h=h+∂L∂W⊙∂L∂WW=W−lr∗1h∂L∂Wh = h + \frac{\partial L}{\partial W} \odot \frac{\partial L}{\partial W}\\ {}\\ W = W - lr * \frac{1}{\sqrt{h}} \frac{\partial L}{\partial W} h=h+∂W∂L​⊙∂W∂L​W=W−lr∗h​1​∂W∂L​

class AdaGrad:
    def __init__(self, lr=0.01):
        self.lr = lr
        self.h = None

    def update(self, params, grads):
        if self.h is None:
            self.h = {}
            for key, val in params.items():
                self.h[key] = np.zeros_like(val)

        for key in params.keys():
            self.h[key] += grads[key] * grads[key]
            params[key] -= self.lr * grads[key] / (np.sqrt(self.h[key]) + 1e-7)

Adam
直观来说即结合Momentum和AdaGrad的方法，通过组合前面两个方法的优点，有望实现参数空间的高效搜索。此外，进行超参数的“偏置校正”也是 Adam 的特征。

权重初始值

对激活函数为sigmoid函数时，如果前一层的节点数为 n，则初始值使用标准差为1n\frac{1}{\sqrt{n}}n​1​的分布
使用 Xavier 初始值后，前一层的节点数越多，要设定为目标节点的初始值的权重尺度就越小

当使用ReLU函数时，一般使用“He初始值”，即标准差为2n\sqrt{\frac{2}{n}}n2​​的高斯分布
直观上可以解释为，因为 ReLU 的负值区域的值为 0，为了使它更有广度，所以需要 2 倍的系数

Batch Normalization

Batch Norm 的思路是调整各层的激活值分布使其拥有适当的广度。为此，要向神经网络中插入对数据分布进行正规化的层，即 BatchNormalization 层
优点：
可以使学习快速进行（可以增大学习率）。
不那么依赖初始值（对于初始值不用那么神经质）。
抑制过拟合（降低 Dropout 等的必要性）。

以进行学习时的 mini-batch 为单位使数据分布的均值为 0、方差为 1 的正规化
μB=1m∑i=1mxiσB2=1m∑i=1m(xi−μB)2x^i=xi−μBσB2+ε\mu_B = \frac{1}{m}\sum^{m}_{i=1}x_i\\{}\\\sigma^2_B = \frac{1}{m}\sum^{m}_{i=1}(x_i - \mu_B)^2\\{}\\\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma^2_B + \varepsilon}} μB​=m1​i=1∑m​xi​σB2​=m1​i=1∑m​(xi​−μB​)2x^i​=σB2​+ε​xi​−μB​​
对 mini-batch 的 m 个输入数据的集合B=[x1,x2,...,xm] B = [x_1,x_2, ... ,x_m] B=[x1​,x2​,...,xm​]求均值μB\mu_BμB​ 和方差σB2\sigma^2_BσB2​。然后，对输入数据进行均值为 0、方差为 1（合适的分布）的正规化。
ε 是一个微小值（比如，10e-7 等），它是为了防止出现除以 0 的情况。

接着，Batch Norm 层会对正规化后的数据进行缩放和平移的变换
yi=γx^i+βy_i = \gamma\hat{x}_i + \beta yi​=γx^i​+β
γ 和 β 是参数。一开始 γ = 1，β = 0，然后再通过学习调整到合适的值。

class BatchNormalization:
    def __init__(self, eps=1e-5, momentum=0.9):
        self.eps = eps          # 防止分母为0的小常数
        self.momentum = momentum # 滑动平均动量
        # 可学习参数（缩放+平移，神经网络自己学）
        self.gamma = None
        self.beta = None
        # 测试时用的 均值/方差（滑动平均累计）
        self.moving_mean = None
        self.moving_var = None

        # 反向传播需要缓存的变量
        self.x_hat = None  # 归一化后的数据
        self.x = None      # 输入数据
        self.batch_size = None # 批次大小

    def forward(self, x, train_flg=True):
        """前向传播"""
        self.x = x
        self.batch_size = x.shape[0] # 批次大小（N）

        # 初始化参数（第一次运行时）
        if self.gamma is None:
            self.gamma = np.ones(x.shape[1:])  # 初始缩放=1
            self.beta = np.zeros(x.shape[1:])  # 初始平移=0
            self.moving_mean = np.zeros(x.shape[1:])
            self.moving_var = np.ones(x.shape[1:])

        # ===== 训练模式：用当前批次的均值/方差 =====
        if train_flg:
            # 计算批次均值、方差（适配全连接层/CNN层）
            axis = tuple(range(1, x.ndim))  # 除了批次N，所有维度求均值
            mu = np.mean(x, axis=axis, keepdims=True)
            var = np.var(x, axis=axis, keepdims=True)

            # 归一化
            self.x_hat = (x - mu) / np.sqrt(var + self.eps)
            # 缩放+平移（最终输出）
            out = self.gamma * self.x_hat + self.beta

            # 更新滑动平均均值/方差（给测试用）
            self.moving_mean = self.momentum * self.moving_mean + (1 - self.momentum) * mu
            self.moving_var = self.momentum * self.moving_var + (1 - self.momentum) * var

        # ===== 测试模式：用累计的滑动均值/方差 =====
        else:
            self.x_hat = (x - self.moving_mean) / np.sqrt(self.moving_var + self.eps)
            out = self.gamma * self.x_hat + self.beta

        return out

    def backward(self, dout):
        """反向传播（计算梯度）"""
        axis = tuple(range(1, dout.ndim))
        # 梯度公式（标准BN反向传播推导）
        dx_hat = dout * self.gamma
        dvar = np.sum(dx_hat * (self.x - self.moving_mean) * -0.5 * (self.moving_var + self.eps)**(-1.5), axis=axis, keepdims=True)
        dmu = np.sum(dx_hat * -1 / np.sqrt(self.moving_var + self.eps), axis=axis, keepdims=True) + dvar * np.mean(-2 * (self.x - self.moving_mean), axis=axis, keepdims=True)

        # 输入x的梯度
        dx = dx_hat / np.sqrt(self.moving_var + self.eps) + dmu / self.batch_size + dvar * 2 * (self.x - self.moving_mean) / self.batch_size
        # 可学习参数gamma、beta的梯度
        dgamma = np.sum(dout * self.x_hat, axis=axis, keepdims=True)
        dbeta = np.sum(dout, axis=axis, keepdims=True)

        return dx, dgamma, dbeta

正则化

过拟合
发生过拟合的原因主要是：模型拥有大量参数、表现力强；训练数据少

权值衰减是一直以来经常被使用的一种抑制过拟合的方法。该方法通过在学习的过程中对大的权重进行惩罚，来抑制过拟合。
为损失函数加上权重的平方范数（L2 范数）。用符号表示的话，如果将权重记为 WWW，L2 范数的权值衰减就是12λW2\frac{1}{2}\lambda W^221​λW2，然后加到损失函数上。
这里，λ 是控制正则化强度的超参数。λ设置得越大，对大的权重施加的惩罚就越重。
对于所有权重，权值衰减方法都会为损失函数加上12λW2\frac{1}{2}\lambda W^221​λW2。因此，在求权重梯度的计算中，要为之前的误差反向传播法的结果加上正则化项的导数λWλWλW

如果网络的模型变得很复杂，我们会使用 Dropout 方法，即在学习的过程中随机删除神经元的方法

class Dropout:
    def __init__(self, dropout_ratio=0.5):
        self.dropout_ratio = dropout_ratio
        self.mask = None

    def forward(self, x, train_flg=True):
        if train_flg:
            self.mask = np.random.rand(*x.shape) > self.dropout_ratio
            return x * self.mask
        else:
            return x * (1.0 - self.dropout_ratio)

    def backward(self, dout):
        return dout * self.mask

超参数最优化

一开始先大致设定一个范围，从这个范围中随机选出一个超参数（采样），用这个采样到的值进行识别精度的评估；然后，多次重复该操作，观察识别精度的结果，根据这个结果缩小超参数的“好值”的范围。通过重复这一操作，就可以逐渐确定超参数的合适范围。
