一.帧差法

帧差法（Frame Difference Method）是 OpenCV 中一种简单高效的运动目标检测技术，属于背景减除（Background Subtraction）的基础方法之一，通过计算视频序列中连续帧之间的像素差异来识别和定位场景中的动态对象。

数学模型：

D(t) = | I(t) − I(t-1) |

I(t)：当前帧灰度图像
I(t-1)：前一帧灰度图像
D(t)：差分结果图（像素差值绝对值）

import cv2
import numpy as np

# 初始化摄像头
cap = cv2.VideoCapture(0)

# 读取前两帧
ret, prev_frame = cap.read()
prev_gray = cv2.cvtColor(prev_frame, cv2.COLOR_BGR2GRAY)
prev_gray = cv2.GaussianBlur(prev_gray, (21, 21), 0)  # 高斯模糊降噪

while True:
    # 读取当前帧
    ret, curr_frame = cap.read()
    if not ret:
        break

    # 预处理
    curr_gray = cv2.cvtColor(curr_frame, cv2.COLOR_BGR2GRAY)
    curr_gray = cv2.GaussianBlur(curr_gray, (21, 21), 0)

    # 计算帧差
    frame_diff = cv2.absdiff(prev_gray, curr_gray)

    # 阈值处理（自适应阈值效果更好）
    _, thresh = cv2.threshold(frame_diff, 25, 255, cv2.THRESH_BINARY)

    # 形态学优化
    thresh = cv2.dilate(thresh, None, iterations=2)
    thresh = cv2.morphologyEx(thresh, cv2.MORPH_CLOSE, None)

    # 轮廓检测与绘制
    contours, _ = cv2.findContours(thresh.copy(), cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    for contour in contours:
        if cv2.contourArea(contour) > 500:  # 过滤小噪声
            (x, y, w, h) = cv2.boundingRect(contour)
            cv2.rectangle(curr_frame, (x, y), (x+w, y+h), (0, 255, 0), 2)

    # 显示结果
    cv2.imshow("Frame", curr_frame)
    cv2.imshow("Frame Difference", frame_diff)
    cv2.imshow("Threshold", thresh)

    # 更新前一帧
    prev_gray = curr_gray

    # 退出条件
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()

优点：
计算复杂度低：无需复杂背景建模，适合实时性要求高的场景（如监控系统）
实现简洁：仅需基础 OpenCV 函数即可完成
适应性强：对简单场景（背景变化小）效果良好

缺点
对光照敏感：环境光线变化会产生大量虚假运动区域
易产生空洞：运动目标内部可能出现黑色区域，影响完整轮廓提取
无法检测静止目标：仅能识别动态物体，对停止运动的目标失效
双影问题：快速运动目标可能在差分结果中出现双重轮廓

二.背景剪除器

背景剪除器（背景减除）是 OpenCV 中鲁棒性更强的运动目标检测技术，核心是动态构建并更新背景模型，通过将当前视频帧与学习到的背景模型做差分，精准分离出前景（运动目标）和背景（静止 / 缓慢变化区域），是视频监控、智能分析的首选基础算法。

核心剪除器
OpenCV 封装了成熟的背景剪除器，无需手动建模，直接调用即可：
MOG2（最常用）：高斯混合模型，自适应光照变化，支持阴影检测（可关闭），通用性最强；
KNN：K 近邻模型，对复杂背景（如晃动的树叶、水波）适配性更好，精度更高；
GMG：基于贝叶斯概率的模型，需要较长的背景学习时间，早期版本常用；
CNT：轻量级模型，计算速度极快，适合低性能设备（如树莓派）。

bg_subtractor = cv2.createBackgroundSubtractorMOG2(
    history=500,    # 背景学习时长
    varThreshold=40,# 差异阈值
    detectShadows=True # 开启阴影检测（阴影标记为灰色）
)

# 方法2：KNN（复杂场景用）
# bg_subtractor = cv2.createBackgroundSubtractorKNN(
#     history=500,
#     dist2Threshold=400.0,
#     detectShadows=True
# )

while True:
    ret, frame = cap.read()
    if not ret:
        break

    # ===================== 核心：生成前景掩码 =====================
    fg_mask = bg_subtractor.apply(frame)

    # 掩码优化：消除噪点、填补空洞
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
    fg_mask = cv2.morphologyEx(fg_mask, cv2.MORPH_OPEN, kernel)  # 开运算去噪
    fg_mask = cv2.morphologyEx(fg_mask, cv2.MORPH_CLOSE, kernel) # 闭运算补洞

    # 提取运动目标（过滤小噪声）
    contours, _ = cv2.findContours(fg_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    for cnt in contours:
        if cv2.contourArea(cnt) > 600:  # 忽略小面积噪点
            x, y, w, h = cv2.boundingRect(cnt)
            cv2.rectangle(frame, (x, y), (x+w, y+h), (0, 255, 0), 2)

背景剪除器靠动态背景建模解决了帧差法的光照、空洞、噪声问题；OpenCV 内置 MOG2（通用）、KNN（复杂场景）是最常用的两种实现；代码简洁、鲁棒性强，是运动目标检测的首选方案。
