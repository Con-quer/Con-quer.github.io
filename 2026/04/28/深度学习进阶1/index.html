余弦退火

余弦退火是一种学习率调度策略，借鉴材料科学中 “退火” 概念 —— 先高温加热再缓慢冷却使材料达到稳定状态
高温阶段（高学习率）：帮助模型跳出局部最优解，探索广阔参数空间
冷却阶段（学习率平滑下降）：使模型平稳接近全局最优，减少震荡
学习率变化遵循余弦函数曲线，避免传统阶梯式衰减的生硬突变
ηt=ηmin+0.5×(ηmax−ηmin)×(1+cos(π×tT))η_t = η_{min} + 0.5 × (η_{max} - η_{min}) × (1 + cos(π × \frac{t}{T}))ηt​=ηmin​+0.5×(ηmax​−ηmin​)×(1+cos(π×Tt​))
代码实现：

def cosine_annealing(current_epoch, epochs, lr_max, lr_min):

    cosine = np.cos(np.pi * current_epoch / epochs)
    lr = lr_min + 0.5 * (lr_max - lr_min) * (1 + cosine)
    return lr

optimizer.lr = cosine_annealing(current_epoch, epochs, lr_max, lr_min)

残差块

在残差块映射出f(x)−xf(x) - xf(x)−x然后再加上xxx完成映射再输出，强行拉高「原始输入特征」在最终输出里的权重占比，避免多层卷积、非线性变换把浅层原生特征（边缘、纹理、基础轮廓）稀释、覆盖甚至丢失。

得注意的是，所谓映射出f(x)−xf(x) - xf(x)−x再加xxx只是理解上来讲，实际映射就是f(x)+xf(x)+xf(x)+x，无需复杂的减法操作

这是我用numpy模拟实现的残差块，当canchafou为True时，先生成支路的1∗11*11∗1卷积层，再生成主路的卷积块

def vgg_block(num,num_convs,in_channels,out_channels,canchafou,stride = 1):
    if canchafou:

        conv_name = f"conv_{num}_res"

        conv = Convolution(in_channels=in_channels,out_channels=out_channels,
                                                kernel_size=1,stride=stride,
                                                res=True,if_res_num_conv=num_convs)

        total_layers.append(conv)

        to_name_layers[conv_name] = conv
    for i in range(num_convs):

            conv_name = f"conv{num}_{i}"
            bn_name = f"bn{num}_{i}"
            relu_name = f"relu{num}_{i}"

            conv = Convolution(in_channels=in_channels,out_channels=out_channels,
                                                    kernel_size=3,pad=1,stride=1)
            bn = BatchNorm2d(out_channels)
            relu = Relu()
            if i == num_convs - 1:
                bn.res = True

            total_layers.append(conv)
            total_layers.append(bn)
            total_layers.append(relu)

            to_name_layers[conv_name] = conv
            to_name_layers[bn_name] = bn
            to_name_layers[relu_name] = relu

            in_channels = out_channels
    pool_name = f"pool{num}"
    pool = (Pooling(stride=2,pool_h=2,pool_w=2))
    total_layers.append(pool)
    to_name_layers[pool_name] = pool

传播时根据卷积层数来进行跨越相加即可

def forward(self, x,train_flg = True):
    skip = -1
    for layer in self.layers:
        if isinstance(layer,Convolution):
            if layer.res == True:
                #self.temp_of_conv_num = layer.if_res_num_conv
                skip = 5
                self.res = layer.forward(x)
                continue
        if skip > 0:
            skip -= 1
            if isinstance(layer,(BatchNorm2d,Dropout)):
                x= layer.forward(x,train_flg)
            else:
                x = layer.forward(x)
            continue
        elif skip == 0:
            x = x + self.res
            skip = -1
            self.res = None
            layer.res = True
            #layer.if_res_num_conv = self.temp_of_conv_num

        if isinstance(layer,(BatchNorm2d,Dropout)):
            x= layer.forward(x,train_flg)
        else:
            x = layer.forward(x)
    return x

def backward(self, dout=1):
    dout = self.last_layer.backward(dout)
    skip = -1
    self.res_dout = None 

    for layer in reversed(self.layers):

        if isinstance(layer, BatchNorm2d) and layer.res == True:
            skip = 4  
            self.res_dout = dout

        if skip > 0:
            skip -= 1
            dout = layer.backward(dout)
            continue

        elif isinstance(layer, Convolution) and layer.res == True:

            shortcut_dout = layer.backward(self.res_dout)
            dout += shortcut_dout
            skip = -1
            continue

        dout = layer.backward(dout)

    return dout

训练意外

这是我在用单个两层卷积的残差块训练的MNIST-10手写数字集模型，训练出现了意外的结果

图像显示训练中训练集和测试集的精度突然一起快速下降，而损失却几乎不变
再分析后得出结论：

1.损失的图像是 matplotlib 绘图的「数量级视觉欺骗」， Loss曲线不是不动，是「初始 Loss 太大，把 Y 轴尺度拉得太宽」，后期微小的 Loss 变化被完全压缩，肉眼看起来像一条平线

2.断崖式下降则是因为浅网络参数少、结构简单，随机初始化的权重，碰巧拟合了数据的「表面噪声 / 简单巧合」，而不是真正学到数据的核心特征，即伪收敛。
