1. HSV

作用：
把图像信息拆成「色相」+「饱和度」+「明度」 三个独立维度，是最适合做人眼视觉、颜色识别、抗光照处理的颜色空间。

（1）色相
标准范围：0° ~ 360°（像一个颜色圆环）
OpenCV 里为了存成 8 位图，压缩成：0 ~ 179

（2）饱和度
范围：0 ~ 255
S ≈ 0：灰色、发白、没颜色；S 越大：颜色越鲜艳、越纯（灰度图的S为0）
作用：过滤掉灰色背景，只保留鲜艳的彩色区域

（3）明度
范围：0 ~ 255
V = 0：纯黑；V = 255：最亮
照片的光照变化指挥改变V，H基本不变

例：

hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

# 设定颜色范围（示例：提取红色）
lower_red1 = np.array([0, 120, 70])
upper_red1 = np.array([10, 255, 255])

lower_red2 = np.array([170, 120, 70])
upper_red2 = np.array([179, 255, 255])

# 生成掩码
mask1 = cv2.inRange(hsv, lower_red1, upper_red1)
mask2 = cv2.inRange(hsv, lower_red2, upper_red2)
mask = cv2.bitwise_or(mask1, mask2)

# 按掩码提取结果
result = cv2.bitwise_and(img, img, mask=mask)

2. MatchTemplate模板匹配器

通过模板，找出大小，方向，形状，颜色完全相同的图案
返回结果矩阵，即一张「匹配度灰度图」

match = cv2.matchTemplate(gray,template,cv2.TM_CCOEFF_NORMED)

locations = np.where(match>=0.95) #控制匹配分数阈值
for p in zip(*locations[::-1]):  #解包可获得每个图案的坐标（左上角）
    x1,y1=p[0],p[1]

    #注意：解包出来的点很多，紧挨着的点，不能直接用，需要阈值控制两点之间的最小距离
    if abs(x1-last_x)<50 and abs(y1-last_y)<50: #匹配点之间小于50则不计数
        continue
    last_x,last_y = x1,y1

3. absdiff()求绝对值差

可以通过两张图片逐个像素求差，得到一张差异图，便于处理背景不变的图片或者视频

diff = cv2.absdiff(img1, img2)

4. ploylines画曲线

cv2.polylines(
img,        # 要绘制的图像（numpy数组）
pts,        # 折线顶点坐标（格式有严格要求）
isClosed,   # 是否闭合折线（True=首尾相连，False=开放）
color,      # 线条颜色（BGR格式）
thickness=1,# 线条宽度
lineType=cv2.LINE_AA, # 抗锯齿（可选）
shift=0     # 坐标缩放（一般不用）

)
cv2.polylines的pts参数必须是列表包裹的numpy数组（dtype=np.int32）
