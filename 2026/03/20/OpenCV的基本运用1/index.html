OpenCV是计算机视觉领域的工业级标准工具，覆盖图像 / 视频处理、特征提取、目标检测、深度学习、三维视觉所有核心场景。

1.基本运用
读取本地图像、显示图像、保存处理后的图像，是 OpenCV 的入口操作，用于加载素材、保存结果、可视化调试。
|基础函数| 功能 |
|—-|—-|
|cv2.imread(path, flag) | 读取图像 （参数2：1=彩色，0=灰度，-1=带透明通道） |
| cv2.imshow(name, img) | 显示图像（必须配合 waitKey() 使用） |
| cv2.imwrite(path, img) | 保存图像（支持 jpg/png/bmp） |
| cv2.waitKey(delay) | 等待按键（0 = 无限等待，数字 = 延时毫秒） |
| cv2.destroyAllWindows() | 关闭所有窗口 ，释放资源 |

2.图像处理
使图像尺寸统一、去冗余区域、颜色标准化、角度校正
（1）图像基础属性
获取图像尺寸、裁剪图像、缩放 / 旋转 / 翻转、转换色彩空间（视觉任务最核心预处理）。

h, w, ch = img.shape #获取高度，宽度，通道数
size = img.size      #获取像素总数即h*w*ch
dtype = img.dtype    #获取数据类型

（2）色彩空间转换
OpenCV 默认是 BGR，而主流工具是 RGB，灰度图用 GRAY，颜色识别用 HSV：

img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
img_gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
img_hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

（3）几何变换

crop = img[100:300, 200:400]  #切片：[y起始:y结束, x起始:x结束]

resize = cv2.resize(img, (300, 200)) #2. 缩放：宽, 高

M = cv2.getRotationMatrix2D((w//2, h//2), 45, 1)  # 3. 旋转：取定中心、角度、缩放比例
rotate = cv2.warpAffine(img, M, (w, h)) # 图形变换

flip = cv2.flip(img, 1)# 4. 翻转（0=上下翻转，1=左右翻转，-1=对角翻转）

3. 图像绘图标注
在图像上画线、矩形、圆、文字，用于标注检测框、标记关键点、输出结果。用于目标检测框标注、关键点标记、结果文字输出、调试可视化。

cv2.line(img, (50,50), (200,200), (0,0,255), 2)  #画直线：起点、终点、颜色(BGR)、粗细

cv2.rectangle(img, (50,50), (200,200), (255,0,0), 2) #画矩形：左上角、右下角、颜色、粗细（-1=填充）

cv2.circle(img, (150,150), 50, (0,255,0), -1) #画圆：圆心、半径、颜色、粗细

cv2.putText(img, "OpenCV", (50,300), cv2.FONT_HERSHEY_SIMPLEX, 1, (255,255,255), 2) #写文字：内容、位置、字体、大小、颜色、粗细
